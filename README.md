# Materia Medica

A personal database of medicinal plants: botanical names, names in English, Danish and French, families, and medicinal properties.

**Live site:** https://laureanneappel.github.io/materia-medica/

**Repository:** https://github.com/laureanneappel/materia-medica

## Reference

The properties come from the PDF **Egenskaber, redigeret 21.9.26** (kept in the project folder, not in git). It decides:

- which properties exist (the Danish headings)
- which plants are on the site, and which properties each plant has
- the botanical names used

Every plant on the site is in the PDF: 157 plants, 100 properties.

## Languages

The site is in **Danish** (default), **English** and **French**; the EN / DA / FR buttons switch between them.

- Property names in Danish are the exact headings from the PDF.
- Plant names, labels, families and the footer are translated.
- Text written about a plant is written once per language (see [Writing about a plant](#writing-about-a-plant)).

## Pages

- **index.html** - all plants as illustrated cards, with search by name and filters by property (type to find one) and family
- **property-statistics.html** - every property with the number of plants that have it: click to see the plants, sort A–Z or by number of plants, search properties and plants. Properties with subtypes (e.g. Antiinflammatoriske) are grouped
- **plant.html** - the page for every plant (`plant.html?p=hawthorn`); it builds itself from the data. Under the plant name: family and names, then the properties as tags, then the written text, with the plant's botanical plate (if it has one) on the right beside them; at the bottom, the 6 plants sharing the most properties. Plates live in `images/plants/` and are set in `plants-data.js` with `image` and `imageCredit`. After adding a plate, run `python3 tools/make-thumbs.py` to make its small version for the main page (`images/plants/thumbs/`). Properties and family link to the plant list filtered on them (`index.html?property=Astringent`, `index.html?family=Rosaceae`)
- **404.html** - sends old plant addresses (`plants/hawthorn.html`) to the new page

## Files

| File | What it is |

| `plants-data.js` | All plants: names, family, properties. Edit names and families here. |
| `i18n.js` | Translations: labels, property names, families |

## When the PDF changes

Save the new PDF in the project folder (name starting with `Egenskaber`), then:

```bash
python3 tools/sync-from-pdf.py --check   # show what would change
python3 tools/sync-from-pdf.py           # apply it
```

The tool also checks the whole site: every plant has its names, family and page, everything is translated, and there are no stray pages. If anything is wrong, it stops without changing anything and says what to do.

Run `python3 tools/sync-from-pdf.py --check` any time you've edited something by hand. Details in [README-TRANSLATIONS.md](README-TRANSLATIONS.md) and [PROPERTIES-REFERENCE.md](PROPERTIES-REFERENCE.md).

Nothing needs installing: it uses the Python and Swift that come with the macOS developer tools.

## Adding a plant

1. Add it to the PDF, and to `plants-data.js`:

```javascript
{
  "commonName": "Hawthorn",
  "botanicalName": "Crataegus arter",
  "family": "Rosaceae (Rose family)",
  "danishName": "Hvidtjørn",
  "frenchName": "Aubépine",
  "properties": [],
  "status": "enabled",
  "fileSlug": "hawthorn"
}
```

2. Run the sync tool; it fills in the properties.

The plant gets its page automatically (`plant.html?p=<fileSlug>`).

## Writing about a plant

Each plant's written text lives in its own file, `content/<fileSlug>.html` (for example `content/hawthorn.html`). Parts without text are hidden on the published site; when you view the site on your own computer they show an `[Add … here]` reminder instead.

The file has one `<section>` per part of the page, and one paragraph per language; the page shows the chosen language:

```html
<section data-section="habitat">
    <h3 data-i18n="plant.habitat">Habitat</h3>
    <p data-lang="en"><strong>Sunlight:</strong> Prefers partial shade.</p>
    <p data-lang="da"><strong>Lys:</strong> Foretrækker halvskygge.</p>
    <p data-lang="fr"><strong>Ensoleillement :</strong> Préfère la mi-ombre.</p>
</section>
```

Sections: `habitat`, `constituents`, `parts-used`, `side-effects`, `uses`, `taste`, `effect`, `references`. `side-effects` and `uses` only appear on plants that have them; `taste`, `effect` and `references` are hidden for now. Leave out the ones you haven't written yet. The layout of every plant page is in `plant.html`; change it once and all plants follow.

## Viewing locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publishing

The live site is built by GitHub Pages from the `main` branch. Commit and push:

```bash
git push
```

The site updates within a minute or two.
